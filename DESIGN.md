# Design System: Krisha's Portfolio — Retro 70s Flower × Soft-Skill Premium

## Palette

### Primary Earth Tones (70s Retro)
- **Olive Green**: `#6B7D3F` — Primary accent, nav, buttons
- **Rust Red**: `#A64642` — Secondary accent, highlights, borders
- **Mustard Yellow**: `#D4A574` — Warm accent, hover states
- **Cream**: `#F5EDE0` — Primary background, off-white

### Secondary Accents
- **Warm Beige**: `#E8DCC0` — Cards, subtle backgrounds
- **Muted Brown**: `#7A6B5D` — Text, secondary elements
- **Peachy Coral**: `#D99F8C` — Soft accent, gentle highlights
- **Sage Green**: `#A3B19C` — Tertiary accent, delicate elements

### Text Colors
- **Dark Brown**: `#3E3735` — Primary text, headers
- **Mid Brown**: `#6B5F57` — Secondary text, descriptions

## Typography

- **Headlines**: Bold serif with character (e.g., Playfair Display) — warm, retro feel
- **Body**: Warm serif (e.g., Crimson Text) — approachable, readable
- **Navigation**: Serif or rounded sans — friendly, retro without being cold

## Design Language

**Overall Vibe**: 1970s vintage with organic, natural energy. Flower motifs, soft curves, warm earth tones. Feels handcrafted, approachable, and alive—not sterile or corporate.

### Hero/Welcome Section
- Cream background with subtle floral pattern or texture overlay
- Olive green sidebar or accent bar (optional)
- Warm serif heading ("Welcome!")
- Simple, centered layout with breathing room

### Navigation
- Sidebar or horizontal bar in warm cream/beige
- Olive green buttons or hover states
- Rounded corners, soft shadows
- Labels in warm brown or rust red

### Project Cards
- Warm beige background with soft rounded corners
- Rust red or olive green border (thick, warm)
- Image area with gentle shadow
- Project name in warm serif, dark brown
- Description in mid-brown
- Tech badges: Olive green background, cream text, rounded pill style
- Hover: slight lift, peachy coral accent appears, soft shadow grows

### Project Detail Page
- Warm cream background
- Large hero image with rounded corners and warm border
- Content in narrow reading width (650–750px)
- Section headers in rust red or olive green
- Tech stack badges: Olive green, arranged as pills
- Links as warm buttons with mustard/peachy accents

### About Section
- Two-column layout (image + text on desktop)
- Image with rounded corners and soft border
- Skills displayed as warm badges
- Generous whitespace, breathing room

### Contact Section
- Form fields with warm beige backgrounds, olive green borders
- Buttons: Olive green background, cream text, rounded, soft shadows
- Contact info box: warm beige background, rust red accent

### Footer
- Warm cream or light beige background
- Dark brown text
- Rust red accent links
- Soft divider line above

## Visual Details

- **Borders**: Thick, warm (rust red, olive green), rounded corners on most elements
- **Shadows**: Soft, warm (brown-tinted), minimal elevation
- **Patterns**: Subtle floral or organic texture overlays (70s wallpaper aesthetic, light opacity)
- **Ornaments**: Small stylized flowers, organic shapes at section breaks, card corners
- **Curves**: Rounded corners (8–12px) on buttons, cards, images—soft, organic feel
- **Spacing**: Generous padding and margins, breathing room between sections
- **Imagery**: Warm-toned photos, organic textures, nature-inspired

## Spacing & Rhythm
- Base rhythm: 1.5rem, scale 0.75x–2rem
- Sections: 3–4rem padding top/bottom
- Cards: 1.5–2rem padding
- Reading width: 650–750px (text blocks)

## Responsive
- Mobile: Single column, larger touch targets, vertical layout
- Tablet: 2-column project grid, flexible sidebar
- Desktop: 3-column project grid, optional sidebar nav, comfortable spacing

## Soft-Skill Enhancements (Premium Layer)
Applied high-end visual design principles from taste-skill:

### Micro-interactions & Motion
- **Easing**: Cubic-bezier(0.23, 1, 0.320, 1) for smooth, natural motion
- **Transitions**: 0.35s for all interactive elements
- **Hover**: Soft multi-layer shadows with depth layering instead of single harsh shadows

### Tactile Premium Feel
- **Film-grain texture**: Subtle noise overlay (0.04% opacity) for physical, crafted aesthetic
- **Soft shadows**: Layered shadows with decreasing opacity (not harsh drop shadows)
- **Breathing space**: Increased padding (5rem section spacing) and grid gaps (2.5rem) for luxury whitespace

### Typography Excellence
- **Serif hierarchy**: Premium serif stack (Crimson Text fallback to Lora, Garamond) for warmth
- **Display fonts**: Playfair + premium serif alternates (Bodoni Moda, Cormorant) for editorial elegance

### Visual Philosophy
- Organic warmth without coldness
- Haptic depth (tactile, touchable aesthetic)
- Anti-corporate: No harsh edges, no generic defaults
- Human-centered: Spacing and micro-motion feel intentional and caring
